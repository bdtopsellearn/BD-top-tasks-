🔧 Free Proxy Setup

Free মডেলগুলো (Opus 4.8, Sonnet 4.6, Haiku 4.5) ব্যবহার করতে local proxy চালু করতে হবে। নিচের command চালাও:

npm start

অথবা freemodel-cc-proxy repo থেকে:

git clone https://github.com/bigdata2211it-web/ai-freemodel-cc-proxy
cd ai-freemodel-cc-proxy && npm start

FreeModel key লাগবে: freemodel.dev থেকে নাও।

Proxy চালু থাকলে: http://localhost:11440
